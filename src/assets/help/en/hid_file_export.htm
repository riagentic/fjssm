Export  (Project Menu)

Exports the project to a .csv file with the following structure, editable in most spreadsheet applications:

#-------------------------------------------------------
# Structure of an m x n benchmark CSV file
# - CSV fields separated by semicolons, [value]
#-------------------------------------------------------

Name;[Project name]
Date;[Project creation date]
Author;[Decision maker name]
;
Type:;[Problem type; 0-crisp,1-fDD,2-fPT,3-FAll]
Jobs:[Number of jobs]
Machines[Number of machines]
;
[Machine name 1]
[Machine name 2]
[..]
[Machine name m]
;
[Job name 1];[due date 1];[alfa1];[beta1];[kappa11];[kappa21];[kappa31];
;[..]
[Job name n];[due date n];[alfan];[betan];[kappa1n];[kappa2n];[kappa3n];
;
;[machine11];[processing time11];[...];[...];[machine1m];[processing time1m]
;...
;[machinen1];[processing timen1];[...];[...];[machinenm];[processing timenm]
